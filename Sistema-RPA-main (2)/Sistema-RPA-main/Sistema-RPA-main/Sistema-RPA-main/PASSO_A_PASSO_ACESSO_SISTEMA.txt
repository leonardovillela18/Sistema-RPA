PASSO A PASSO PARA RODAR E ACESSAR O SISTEMA RPA

1) Abra um terminal na pasta backend:
Set-Location "c:\Users\Administrador\Desktop\Sistema RPA\Sistema-RPA\Sistema-RPA-main (2)\Sistema-RPA-main\Sistema-RPA-main\Sistema-RPA-main\backend"

2) Inicie o servidor:
npm start

3) Confirme que o backend subiu:
Abra no navegador:
http://localhost:3000/api/health

Se estiver tudo certo, deve retornar:
{"ok":true,"message":"API online."}

4) Abra o sistema no navegador:
http://localhost:3000

Ou direto na tela de login:
http://localhost:3000/acesso.html

5) Credenciais de admin padrao:
Login: admin
Senha: admin1

6) Verificar se as alteracoes foram salvas no banco:
Abra o arquivo:
backend\database\app-db.json

7) Para parar o servidor:
No terminal onde o backend esta rodando, pressione:
Ctrl + C

8) Se a porta 3000 estiver em uso, rode em outra porta:
$env:PORT='3010'; npm start

Depois acesse:
http://localhost:3010
